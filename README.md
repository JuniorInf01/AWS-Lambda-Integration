Informe de Proyecto: Procesador de Imágenes Serverless Multientorno en AWS

Datos: Infantes Rondo, Junior David / 000279891

Este proyecto consiste en el diseño, despliegue y validación de una arquitectura orientada a eventos en la nube de AWS. El sistema permite la ingesta de imágenes vía API, su almacenamiento escalable y su procesamiento asíncrono (recorte circular) dentro de una red privada, garantizando alta disponibilidad, seguridad y optimización de costos.
